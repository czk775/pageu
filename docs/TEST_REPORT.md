## 8. 发现问题

### 问题 1：AI 返回数组过短时不会补足展示内容

- 等级：P2 普通
- 现象：`normalizeAnalysisPayload` 原逻辑只对 AI 返回数组去重和截断。如果真实 AI 返回数组少于 3 项，页面仍会展示过少内容，不满足 Phase 7 对 3-6 项结构化结果的要求。
- 影响：分析页卡片内容可能不足，演示稳定性下降。
- 修复建议：将 AI 返回数组与 Mock fallback 数组合并去重，再截断到最多 6 项。
- 处理结果：已修复。

### 问题 2：真实移动端与多浏览器未完整人工覆盖

- 等级：P3 优化
- 现象：本阶段已覆盖桌面 Chromium、响应式代码路径和手机预览控件，但未执行真实手机设备或 Safari/Edge 的人工截图验收。
- 影响：可能遗漏少量设备特定样式问题。
- 处理结果：按要求不修 P3，记录为后续建议。

### 问题 3：前端 Demo 暴露 VITE API Key 的产品化风险

- 等级：P3 优化
- 现象：真实 AI Key 通过 Vite 前端环境变量进入浏览器环境。
- 影响：正式产品不可接受，但比赛 Demo 可临时使用。
- 处理结果：Phase 7 文档已记录风险；本阶段不改主流程。
