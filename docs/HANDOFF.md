# PageU 项目交接文档

## 1. 当前阶段名称

Phase 5 — 发布页 + 最终个人网站。

## 2. 本阶段完成内容

- 保留 PageU 首页、创建页、Mock AI 分析页和编辑器主流程。
- 完成 `/publish` 发布页，使用 `localStorage` 模拟发布，不接后端、不登录、不真实部署。
- 发布页包含网站预览、模拟网站地址、二维码、访问权限和底部操作。
- 发布页预览读取 `siteDraft`，支持电脑/手机切换。
- 模拟链接固定为 `/site/demo`，支持复制。
- 使用二维码库生成当前网站二维码，支持下载 SVG。
- 新增 `publishDraft`，保存到 `localStorage` 的 `pageu.publish`。
- 访问权限支持公开、私密、密码访问，默认公开，仅保存状态。
- 完成 `/site/:id` 最终个人网站页，直接读取 `siteDraft` 渲染真实网站。
- 新增 `src/renderers/TemplateRenderer.jsx`，负责把 `siteDraft` 渲染为最终个人网站。
- `TemplateRenderer` 支持 Neo、Pure、Flow、Grid、Canvas、Glass 六种模板布局。
- 最终个人网站不包含编辑器布局、控制面板、编辑按钮或顶部导航。
- 最终个人网站底部弱化显示 `Generated by PageU`。
- 补充测试，覆盖发布页、二维码、发布跳转、最终站点和模板切换。

## 6. 如何本地运行

```bash
npm install
npm run dev
```

默认访问 Vite 输出的本地地址，通常是 `http://localhost:5173/`。如端口被占用，可使用：

```bash
npm run dev -- --host 127.0.0.1 --port 5199 --strictPort
```

验证命令：

```bash
npm test
npm run build
```

## 7. 如何验收本阶段

1. 执行 `npm install` 安装依赖。
2. 执行 `npm run dev` 启动项目。
3. 从 `/editor` 点击 `发布网站`，确认跳转 `/publish`。
4. 在 `/publish` 确认标题为 `你的个人网站准备好了`。
5. 确认左下角小U 存在，提示为 `希望它能帮更多人认识你`。
6. 确认发布页展示网站预览，并可切换电脑/手机。
7. 确认网站地址显示 `/site/demo`，复制按钮可点击。
8. 确认二维码正常生成，并可点击下载二维码。
9. 切换访问权限：公开、私密、密码访问，确认状态保存到 `pageu.publish`。
10. 点击 `访问网站`，确认跳转 `/site/demo`。
11. 在 `/site/demo` 确认展示头像占位、姓名、目标岗位、一句介绍、经历、项目、技能、作品、联系方式。
12. 确认最终站点没有编辑器三栏、编辑按钮或控制面板。
13. 在编辑器选择不同模板后发布，确认最终站点布局明显变化。
14. 缩小浏览器宽度，确认发布页和最终站点可以响应式滚动。
15. 执行 `npm test`，确认测试通过。
16. 执行 `npm run build`，确认生产构建通过。

## 8. 当前状态结构

### createDraft

`createDraft` 由 `src/state/CreateDraftContext.jsx` 提供，用于保存创建页输入，并同步到本地存储。

```js
createDraft = {
  basicInfo: {},
  jobInfo: {},
  experiences: [],
  template: 'neo',
  meta: {},
};
```

### analysisResult

`analysisResult` 由 `src/types/analysisResult.js` 中的 `createAnalysisResult(createDraft, userAdjustment)` 派生，不调用真实 AI。

```js
analysisResult = {
  jobKeywords: [],
  abilityFocus: [],
  displayOrder: [],
  highlightedExperiences: [],
  userAdjustment: '',
  updatedAt: '',
};
```

### siteDraft

`siteDraft` 由 `src/lib/draftGenerator.js` 中的 `generateSiteDraft(createDraft, analysisResult)` 生成，编辑器继续实时修改，并保存到 `pageu.siteDraft`。

```js
siteDraft = {
  profile: {},
  sections: [],
  theme: {},
  template: '',
  meta: {},
};
```

### publishDraft

`publishDraft` 由 `src/types/publishDraft.js` 维护，用于模拟发布状态，并保存到 `pageu.publish`。

```js
publishDraft = {
  published: true,
  siteId: 'demo',
  visibility: 'public',
  publishedAt: '',
};
```

## 9. 发布流程

- `/publish` 优先读取 `pageu.siteDraft`。
- 如果没有本地 `siteDraft`，则从当前 `createDraft` 和 `analysisResult` 派生默认草稿。
- 进入发布页后创建或更新 `publishDraft`。
- 网站地址固定为 `/site/demo`。
- 访问权限只写入本地状态，不做真实权限校验。
- 点击 `访问网站` 后跳转 `/site/demo`。

## 10. 模板渲染方式

- `src/renderers/TemplateRenderer.jsx` 是最终网站渲染入口。
- 输入：`siteDraft`。
- 输出：最终个人网站 DOM。
- 六种模板来自 `src/data/templates.js` 的模板 ID。
- 模板差异通过布局结构体现：居中留白、流线时间轴、网格卡片、创意画布、玻璃拟态等。
- `/publish` 使用同一个 renderer 做预览。
- `/site/:id` 使用同一个 renderer 做正式展示。

## 11. 当前未完成内容

- 未接入真实 AI 接口。
- 未接入后端、数据库、登录或真实部署。
- 发布链接固定为 `/site/demo`，没有真实域名。
- 访问权限只保存状态，不做访问拦截。
- 二维码指向当前本地 origin 下的 `/site/demo`。
- 图片上传仍为占位/首字母头像，没有真实图片存储。
